ПЛАНИРОВЩИК: ОСТАВШИЕСЯ УЛУЧШЕНИЯ
Обновлено: 28 октября 2026
История UI и светлой темы — archive/2026-10-28/.
Согласованное оформление и ограничения — decisions.md.

1. P01 / P2. СЕНСОРНЫЕ ЦЕЛИ ОБЩЕГО WEEKPICKER
Стрелки общего WeekPicker пока имеют размер 36×36 px. Увеличить область нажатия до 44 px, сохранив размер иконки и знакомую композицию. Проверять одновременно планировщик и расписание, включая узкую шапку.
Критерий: стрелки удобно нажимаются, соседние действия не перекрываются, оба раздела используют общий компонент.

2. P02 / P2. БОЛЬШАЯ ЗАПОЛНЕННАЯ ДОСКА
- Проверить доступность полосы дней и горизонтальной навигации при большой высоте колонок.
- Оценить закрепление навигации, не закрывающее карточки; список оставить удобной альтернативой без боковой прокрутки.
- Проверить, замечают ли пользователи крайние фильтры на телефоне. Менять их вход только по наблюдаемой проблеме.
Критерий: можно найти день и задачу без возврата к началу длинной доски; подтверждённые проблемы имеют адресные исправления.

3. P03 / P2. ПЕРЕНОС ЗАДАЧИ МЕЖДУ ДНЯМИ
Сохранённая идея пользователя: переносить задачу внутри недели перетаскиванием.
- Сначала определить, какие поля даты/времени меняются при переносе; не считать самостоятельное окончание автоматически равным дню размещения.
- Дать равнозначный перенос через меню/клавиатуру и доступный сенсорный сценарий.
- Показать целевой день, результат и отмену переноса; отказ записи/конфликт не должны оставлять ложное положение карточки.
- Проверять незавершённую форму, длинные колонки и прокрутку. При переносе сохранять ID и остальные реквизиты задачи.
- Новую DnD-библиотеку не добавлять без согласования.
Критерий: одинаковый результат для мыши, клавиатуры и телефона, ошибка сохраняет корректные данные.

4. P04 / P3. ДОПОЛНИТЕЛЬНЫЕ ВОЗМОЖНОСТИ — ПОСЛЕ ОЦЕНКИ
После переноса рассмотреть дублирование задачи с новым ID. Независимые фильтры типа/состояния и быстрый ввод оценивать по реальным сценариям. Повторения и напоминания требуют отдельного описания поведения и не включены автоматически.

5. P05. ПРИЁМКА ОСТАВШИХСЯ ИЗМЕНЕНИЙ
После снятия ограничения браузерной работы: обе темы, 320/390/768/1024/1440/1920 px, 200% масштаб, реальный телефон, много задач, длинные тексты, открытые меню/календарь, смена недели через месяц/год, ошибка записи и клавиатура. Для P01 дополнительно проверить расписание. Старые проверки не закрывают новые функции заранее.

КРАТКИЙ ПЕРЕСКАЗ
Остались области нажатия стрелок, навигация длинной доски и перенос задач с альтернативой перетаскиванию. Дублирование и быстрый ввод — последующие идеи. Выполненная переработка UI и тем из очереди убрана.
