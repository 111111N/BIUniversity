# Рабочие планы

Обновлено: 24 ноября 2026 года.

В очереди осталось **15 крупных групп разработки в 5 направлениях**. Выполненные функции и их технические проверки убраны из рабочих планов; история сохранена в [архиве отчётов](archive/README.md). Отдельно остаются **37 групп ручной приёмки в 8 разделах**: они не закрываются по факту реализации или успешной сборки.

| Направление | Оставшаяся работа | Оценка, ч |
| --- | --- | ---: |
| [G03 — резервные копии](portal-improvements-next-plan.txt) | 8 групп: недостающие источники и схемы, права и зависимости, оставшиеся конфликты, применение с откатом, личная выгрузка | 102–200 |
| [U04 — документы и история](university-administration-development-plan.txt) | 1 группа: документы, приказы, исправления, исторические ФИО и контакты | 24–48 |
| [U05 — подгруппы и потоки](university-administration-development-plan.txt) | 1 группа: состав, доступ и сценарии занятий | 24–48 |
| [U07 — импорт](university-administration-development-plan.txt) | 2 группы: реальный формат Excel и сопоставление людей по внешнему ID | 24–48 |
| [U08 — сервер](university-administration-development-plan.txt) | 3 группы: API и авторизация, транзакции и файлы, миграции и эксплуатация | 160–280 |
| **Разработка и техническая проверка** | **15 групп** | **334–624** |
| [Ручная приёмка](portal-acceptance-checklist.txt) | 37 групп: роли, темы, устройства, ошибки, доступность и предметные сценарии | 48–80 |
| Резерв исправлений | Исправления по результатам общей приёмки и повторная проверка затронутых сценариев | 40–80 |
| **Весь оставшийся план** | **С сервером, приёмкой и резервом** | **422–784** |

Практический ориентир — **около 420–800 часов**. Оценка предварительная, для одного разработчика, знакомого с проектом. Это трудозатраты, а не календарный срок; ожидание решений, исходных данных и доступов в них не включено. Разработка включает техническую проверку, а ручная приёмка и исправления посчитаны отдельно. Если исключить сервер U08, остаток остальных работ с общей приёмкой и резервом — **262–504 часа**; это отдельная граница объёма, не готовность к реальной эксплуатации.

Главные неопределённости: источник исторических прав и старых данных G03, правила документов U04, состав подгрупп U05, образец Excel и внешний ID U07, серверная технология и среда U08. Оценка предполагает сохранение согласованного функционала без новых интеграций. После уточнения этих зависимостей диапазоны нужно пересмотреть.

Согласованные правила — [decisions.md](decisions.md). Непроведённая ручная приёмка остаётся открытой; ограничение пользователя на браузер и Computer Use действует. Необязательные идеи находятся [отдельно от очереди](archive/2026-10-30-deferred-portal-ideas.txt).

У задачи один основной план. После реализации удалять её из очереди, результаты сохранять в архиве. Старые отчёты не служат основанием снова начинать выполненную работу. Снимок архива от 28 октября сохраняется без изменений.
