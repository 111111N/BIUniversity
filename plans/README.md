Доступная без браузера общая очередь: G03 — проектирование личной выгрузки и безопасного восстановления административного архива; развитие учебной модели — U01–U03. Визуальная приёмка остаётся открытой. По действующей просьбе пользователя Computer Use, браузер и управление его окнами не используются. Старые браузерные отчёты не подтверждают новые состояния.

## Правила ведения

- После реализации убирать задачу из рабочего плана. Доказательства и ограничения сохранять отдельным отчётом в архиве; не накапливать «выполнено» между открытыми задачами.
- У каждой общей задачи один владелец. Например, цели стрелок WeekPicker — P01 планировщика, общий список заданий — J03 журнала; другие планы ссылаются на них.
- Различать реализацию, приёмку и необязательную идею. Сборка и тесты не закрывают визуальную или пользовательскую оценку.
- В каждом TXT-плане оставлять краткий пересказ в самом конце.
