Ближайшая очередь разработки — G03. Восстановление данных требует сначала согласовать правила конфликтов и транзакций; текущая проверка архива не подтверждает готовность к восстановлению. Крупные изменения модели ведутся по U01 → U02 → U03, с подготовкой серверных контрактов U08.

Ручные проверки G01, R12, J02, P05, S02 и H01 остаются открытыми до проверки интерфейса. Computer Use не использовать, пока действует ограничение пользователя. Автоматические тесты и сборка не заменяют визуальную приёмку.

У задачи должен быть один основной план. После реализации убирать её из очереди; результаты проверок хранить в архиве. Не превращать рабочие планы в журнал изменений и не возобновлять задачу только по старому отчёту. Кандидаты P3 требуют проверки пользы перед реализацией. Снимок архива от 28 октября сохраняется без изменений.
