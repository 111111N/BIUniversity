СВЕРКА ИСХОДНЫХ СООБЩЕНИЙ ОТВЕТОВ В АРХИВЕ
Дата: 29 октября 2026
Область: G03 — ссылки replyTo у сопоставленных копий личных сообщений.

1. РЕЗУЛЬТАТ
Проверка копий личных сообщений теперь сопоставляет источники ответов.
Для каждой копии replyTo разрешается внутри её собственного диалога,
затем сравнивается постоянный ID доставки найденных исходных сообщений.
Равенство числовых номеров не подтверждает, что ответ ведёт на один источник.
Разные номера допустимы для этой проверки, если оба исходника имеют общий
однозначный ID доставки. Замечание о разных номерах самих копий сохраняется:
проверка истории перенумерации остаётся отдельной задачей.
Используется индекс числовых ID внутри диалога, дополнительно к существующему
индексу доставки. Для каждого ответа не выполняется полный поиск переписки.

2. ЗАМЕЧАНИЯ
Если оба источника найдены и однозначно идентифицированы, но ID доставки
различаются, в ошибку согласованности копий добавляется поле «ссылка ответа».
Одна пара учитывается один раз; конфликты ссылки и других полей объединяются
в одно замечание. Значения исходных текстов и цитат в него не копируются.
Ссылка только у одной копии — замечание для проверки, без автоматического
дописывания. Исходник без ID доставки или с повторяющимся ID доставки —
отдельная непроверенная связь; совпадение текста и номеров её не заменяет.
Если исходник удалён или ссылка ведёт на сам ответ, остаётся существующее
локальное замечание о replyTo. Дополнительная ошибка сравнения копий
не создаётся: общий исходник в таком случае нельзя доказать.
Отсутствующий источник не ищется в другом диалоге, живом хранилище,
старом поколении переписки или встроенных примерах.

3. ОТЧЁТ И СОХРАННОСТЬ
Область «Переписка» объясняет, что ссылки сравниваются по ID доставки
сохранённых исходных сообщений. Замечания входят в существующие пагинацию
и полный JSON-отчёт; указываются ключ общего документа и составной ID ответа.
Тексты исходных сообщений, цитаты, имена файлов и исходный JSON не выводятся.
Исходные документы, номера и ссылки не изменяются, сообщения не доставляются
повторно. Логика рабочего мессенджера и хранилищ не менялась.
Проверка остаётся ограниченной однозначными ящиками и личными контактами,
подтверждёнными учётками архива. Права и полнота истории не подтверждаются.

4. ПРОВЕРКА
Прошли 311 тестов в 14 профильных файлах: backupMessageDelivery,
backupMessagingDocuments, localBackupDocuments, localBackupLearningDocuments,
backupJournalDocuments, backupPlannerDocuments, backupNotificationDocuments,
backupSettingsDocuments, localBackupInspectionService, localBackupInspectionReport,
DocumentReview, InspectionPanel, messageStore и messageDelivery.
Проверены корректные ссылки, общий источник с разными номерами, номер 0,
разные источники при одинаковых номерах, отсутствие ссылки с любой стороны,
старые и неоднозначные ID, удалённые и самоссылочные исходники, объединение
конфликтов, 260 отдельных замечаний, отсутствие личного содержимого в SSR
и полном JSON-отчёте, неизменность архивных и текущих данных.
TypeScript и общий ESLint прошли. Полный набор портала не запускался.
Production-сборка с базой /BIUniversity/ прошла. check:build подтвердил
97 записей манифеста и 122 файла; browserRuntimeChecked=false.
Проверки diff и планов прошли: 52 архивных хеша, 7 рабочих планов,
64 Markdown-ссылки и 7 кратких пересказов. Архивный снимок планов не изменён.

5. ОСТАВШИЕСЯ ЗАДАЧИ
История перенумерации и причинная последовательность ответов, согласование
поколений при восстановлении, неоднозначные/отсутствующие исходники,
права участников, встроенные контакты, черновики и бинарные вложения открыты.
План обновлён: реализованная сверка сохранённых источников убрана из задач,
визуальная приёмка соответствующих замечаний оставлена отдельно.
Темы, телефон, масштаб, клавиатура и длинные ID требуют реальной приёмки.
Браузер, Computer Use и Git-публикация не использовались. Библиотек не добавлено.

КРАТКИЙ ПЕРЕСКАЗ
Копии ответа проверяются по реальному исходному сообщению, а не по совпадению
номеров. Конфликт источников виден в отчёте; удалённые и неоднозначные ссылки
остаются вопросом для проверки без изменения данных и раскрытия переписки.
