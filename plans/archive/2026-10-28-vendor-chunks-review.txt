ПОРТАЛ: РАЗДЕЛЕНИЕ JS И ПРОВЕРКА КЭША СБОРКИ
28 октября 2026
Реализация разбиения G02. Фактическое сетевое и браузерное поведение остаётся в G01/R12.

ИЗМЕНЕНИЯ
1. build/chunks.ts определяет отдельные семейства vendor-react (React/ReactDOM/scheduler), vendor-router и vendor-select. Определяется именно установленный пакет, включая Windows, pnpm и вложенные node_modules. Прикладные модули и остальные библиотеки остаются в автоматическом графе Rollup.
2. manualChunks использует эти границы; private-зависимости и общие служебные функции распределяются Rollup с явно указанным onlyExplicitManualChunks=false. Статический граф проверяется на циклы и зависимость vendor от приложения.
3. Не создан один общий vendor для всех библиотек. D3 остаётся в отложенных чанках графиков; аудит не обнаружил прикладных src-модулей внутри трёх vendor-чанков.
4. Vite всегда создаёт manifest. Новая команда frontend check:build проверяет наличие начальных и отложенных файлов, imports/dynamicImports, базовый путь HTML, отсутствие статических циклов и транзитивной зависимости vendor от входной точки или страницы.
5. Команда показывает сумму JS/gzip начальной статической оболочки с её зависимостями. Отложенный выбранный раздел считается отдельно от оболочки. Скрипт работает локально, ничего не изменяет, сообщает ошибку и возвращает ненулевой код при нарушении проверок.
6. Общий ESLint теперь охватывает также build, scripts и конфигурации. Для Node-файлов заданы Node globals; ограничения прикладных файлов не ослаблены. В README добавлены команда проверки, соответствие базовому пути и ограничения статической проверки.

ПРОВЕРКА ПОЛЬЗЫ ДЛЯ КЭША
Дополнительная сборка выполнена в новой временной папке. В ней plugin только для эксперимента заменил текст загрузки в App.tsx; рабочие исходники приложения не менялись.
Все три vendor-файла сохранили имена с хэшами и совпали побайтно по SHA-256. В сумме это 356753 байта JS / 117822 байта gzip. Из первоначальной оболочки изменился один прикладной файл: 162650 байт / 48186 байт gzip.
Следовательно, при доступном кэше библиотек такая правка не требует их повторной передачи. Это проверка стабильности артефактов, не измерение реального HTTP-кэша или задержки сети. Загрузка конкретного раздела может включать дополнительные отложенные файлы.

ПРОВЕРКИ
Добавлены 27 проверок: 18 для границ vendor-пакетов и 9 для проверяющего скрипта. Покрыты pnpm/Windows/вложенные пакеты, сохранение автоматического разбиения других библиотек, полный начальный граф, отсутствие deferred-файла, неверные импорты/базовый путь, устаревший HTML при наличии старых файлов, цикл, зависимость vendor от страницы и выход пути файла за каталог сборки.
Целевой набор: 58 тестов в 6 файлах прошли, включая реальную конфигурацию ESLint, распознавание ошибок загрузки JS/CSS, границы доступа к расписанию и передачу назначений. После дополнения проверки HTML повторены все 9 тестов скрипта; остальные тесты прошли в расширенном прогоне. Полный набор портала повторно не запускался.
Полный ESLint, включая новые build/scripts/config, прошёл без ошибок и предупреждений. TypeScript проверен tsc -b при production-сборке. Production-сборка с --configLoader native --base /BIUniversity/ прошла. Проверены 93 записи manifest и 117 файлов; статических циклов нет.
Проверена отдельная сборка с изменением App и состав модулей через существующие возможности Rollup/Vite; новых библиотек нет.

ОГРАНИЧЕНИЕ ОКРУЖЕНИЯ
Попытка стандартной загрузки Vite-конфига через esbuild остановилась на отказе изолированной среды читать родительские каталоги до построения приложения. Рабочая production-сборка и эксперимент выполнены с поддерживаемым native loader Node; соответствующий вариант команды добавлен в README. Скрипт build не менялся ради ограничения среды. Обычный loader в этой среде не объявлен успешно проверенным.

КРАТКИЙ ПЕРЕСКАЗ
Оболочка разделена на прикладной код и три стабильных файла библиотек без роста суммарного JS. Проверка с правкой App подтвердила сохранение vendor-файлов для кэша. Добавлена воспроизводимая проверка сборки; реальная браузерная приёмка загрузки остаётся открытой.
