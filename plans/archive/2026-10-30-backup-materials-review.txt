МАТЕРИАЛЫ И ИХ ОБЛАСТИ В АРХИВЕ
Дата: 30 октября 2026
Область: G03, проверка архива перед возможным восстановлением

1. ЧТО ИЗМЕНИЛОСЬ
Добавлена отдельная область «Материалы» для bi-university-cabinet/teacher-files.
Читаются версии 1 и 2: проверяются inline-ключ id, отсутствие автогенератора
и схема индекса scope. Версия 2 требует этот индекс; версия 1 без него
читается с замечанием о совместимости будущего восстановления.
Дополнительные индексы требуют отдельной проверки ограничений записи.
Неподдерживаемая схема не выдаётся за отсутствие конкретного файла.

Каждая запись проверяется независимо: ключ и ID, типы метаданных,
неотрицательный целый размер, корректная дата, Blob и необязательные поля.
Размер, MIME-тип и имя при наличии File сверяются с бинарным значением.
Расхождение метаданных отмечается ошибкой при читаемой схеме;
повреждённая запись не скрывает остальные материалы.
Сводка различает отсутствующее хранилище, пустое и прочитанное с ошибками.

2. ВЛАДЕЛЕЦ И УЧЕБНАЯ ОБЛАСТЬ
Личная область user: проверяется по точно закодированному ID архивной учётки.
Область subject: сверяется с архивным каталогом дисциплин.
Область group: сопоставляется с единственной парой ID дисциплины и группы
из сохранённых каталогов, без разбиения ID по первому двоеточию.
Неоднозначная область, неизвестный ID и недоступный каталог различаются.
Встроенные группы и текущие данные браузера не подставляются.

Поле uploadedBy содержит отображаемое имя, а не подтверждённый ID автора.
Оно не участвует в подборе учётки. Смена роли или состояния существующей
учётки не объявляет историческую ссылку отсутствующей.
Совпадение ID не доказывает права участников или подлинность владельца.
Пустая область, cabinet и отсутствие scope отмечаются как старые общие
материалы без сохранённого ID владельца. Проверка их не переназначает.
Согласованное решение передать старые общие файлы преподавателю сохраняется
для применения восстановления; это отдельная операция, а не действие предпросмотра.

3. ИНТЕРФЕЙС И ОТЧЁТ
В интерфейсе доступны число записей, прочитанных и повреждённых материалов,
число областей с найденными архивными ID и неподтверждённых областей.
Общие предупреждения уточняют границу проверки материалов и прав участников.
Замечания содержат технические ID без имён файлов, описаний, имён загрузивших
и бинарных данных. Полный JSON-отчёт сохраняет все замечания после 200-го.

4. АРХИТЕКТУРА И СОХРАННОСТЬ
Чистый модуль получает tagged-значения и каталоги самого архива.
Бинарные данные не декодируются, файлы не открываются, IndexedDB браузера
не читается и не обновляется. Большой обход допускает отмену.
Повреждённые поля не нормализуются. Бизнес-логика материалов, формат хранения
и существующая миграция не менялись. Новые библиотеки не добавлены.

5. ПРОВЕРКА
609 тестов профиля архива в 25 файлах прошли, включая новые тесты материалов,
интеграцию с общим анализатором, SSR интерфейса и полный JSON-отчёт.
Проверены текущая и старая схемы, пустое и отсутствующее хранилище,
повреждённые записи, расхождение метаданных, владельцы и учебные области,
недоступные каталоги, неоднозначные пары ID, более 200 замечаний и отмена.
Синтетические секретные имена, описания и байты не попадают в отчёт;
исходный архив и текущие данные остаются неизменными.
TypeScript, общий ESLint, production-сборка с базой /BIUniversity/
и check:build прошли: 97 записей манифеста, 122 файла,
browserRuntimeChecked=false. Полный набор тестов портала не запускался.
Проверки diff обоих репозиториев и планов прошли: 52 архивных хеша,
7 рабочих планов, 76 Markdown-ссылок и 7 кратких пересказов.

6. ЧТО ОСТАЛОСЬ
Определить решения для конфликтующих метаданных, старых областей,
неподдерживаемых схем, неизвестных владельцев и неоднозначных учебных связей.
Подтвердить происхождение и реальные права по будущему серверному контракту.
Дополнительные индексы ещё не подтверждают совместимость будущей записи.
Браузерная приёмка счётчиков, длинных ID, тем, телефона, клавиатуры
и скачивания отчёта остаётся в G03. Computer Use не использовался.
Коммитов, отправки в Git и публикации нет. Архивный снимок 52 документов
от 28 октября не изменён.

КРАТКИЙ ПЕРЕСКАЗ
Проверяются записи материалов, их метаданные и сохранённые области по ID архива; владельцы не подбираются по имени, файлы не изменяются, реальные права остаются неподтверждёнными.
