G03: ЗАВИСИМОСТИ ВЕДОМОСТЕЙ В ОБЩЕМ ВЫБРАННОМ НАБОРЕ
Дата: 23 ноября 2026

Результат
Проверка ссылок ведомостей, снимков учебных периодов и времени сохранённых действий выделена из инспектора исходного архива в общий доменный инспектор. Он используется для исходного архива и для согласованного кандидата ведомостей в общем запуске проверки выбранных справочников. Документы и кандидаты уже декодированы; повторного декодирования, чтения живых хранилищ или самостоятельного выбора базового источника не происходит.

Учитываются группы и дисциплины, студенты состава, руководитель и предыдущий руководитель, преподаватели, председатели/члены комиссии, авторы создания/публикации, назначения из истории и авторы исправлений/их событий. Отсутствующий или несогласованный полный источник оставляет связь неподтверждённой. Отсутствие ID в известном полном источнике даёт ошибку. Записи не сопоставляются по именам; текущая роль и блокировка не подтверждают исторические права.

Снимки года/семестра проверяются по уже выбранной полной истории периодов, точной глобальной ревизии и моменту создания основной попытки. Совпадающий текущий семестр не заменяет сохранённую версию. Учебная программа группы, исторический состав и полномочия по-прежнему не считаются подтверждёнными только из наличия ID или периода; назначения старого формата из снимка остаются отдельными замечаниями.

Для исходного архива граница времени остаётся его завершением. Для выбранного набора используется момент общей проверки. Сохранённое действие после этой границы даёт ошибку; будущая дата назначенной сдачи сама по себе допустима. Адрес замечания включает вид записи, поэтому одинаковые ID ведомости, попытки, события и исправления не перекрывают друг друга при дедупликации.

Общий инспектор поддерживает отмену, лимит 25 000 замечаний и текстовый бюджет. Превышение прерывает всю операцию без частичного успешного итога. Сохраняются проверки исходного файла, снимка данных, доступа и ревизии выбора после асинхронной операции. UI получает только замечания и статусы; оценки, даты, составы, источники и хранилища не меняются.
