СВЯЗИ ЖУРНАЛОВ С ЗАНЯТИЯМИ В АРХИВЕ
Дата: 30 октября 2026
Область: G03, чтение архива перед возможным восстановлением

1. ЧТО ИЗМЕНИЛОСЬ
Журналы и события изменения ячеек сверяют стабильный ID занятия
с сохранённой историей опубликованного управляемого расписания.
Проверяется точное совпадение ID занятия, дисциплины и группы.
Принадлежность ключа журнала предварительно определяется по каталогам архива;
при неоднозначной или неизвестной области связь с занятием не подтверждается.
Текущие назначения и состав студентов не используются вместо исторических данных.

Отменённые и перенесённые пары остаются допустимыми историческими ссылками,
если их прежняя дисциплина и группа сохранены в истории расписания.
Новое занятие с тем же ID в другой группе не скрывает старую сохранённую область.
Совпадение ID не подтверждает проведение пары, посещение или права преподавателя.

2. НЕПОДТВЕРЖДЁННЫЕ СВЯЗИ
Отдельные замечания различают:
- старый ключ без стабильного ID управляемого расписания;
- ID, найденный только в черновике, без истории опубликованного занятия;
- ID в истории расписания, но для другой дисциплины или группы;
- ID, которого нет в сохранённой истории расписания.
Если расписание отсутствует или целиком не читается, выдаётся одно замечание
на читаемый список с проверяемыми стабильными ссылками. Читаемая часть
повреждённого расписания не используется как полный индекс занятий.
При непроверенной учебной области остаётся её замечание на список;
оно не дублируется для каждой ячейки. Ссылки при этом считаются неподтверждёнными.
Пустые списки не порождают замечания об отсутствующих связях.
Схема списка и количество записей остаются отдельными результатами проверки.

Старые ключи по дате или демонстрационной нумерации не мигрируются.
Дата, название дисциплины, номер в расписании и встроенные примеры
не заменяют стабильный ID, даже если в архиве есть пара в тот же день.
События roster/demo не считаются изменениями ячеек. Событие ячейки
без ID занятия по-прежнему имеет отдельное замечание проверки значений;
занятие для него не вычисляется из времени события.

3. СВОДКИ И ТЕХНИЧЕСКИЕ ID
В двух существующих сводках показано число совпавших и неподтверждённых ссылок
из читаемых списков. Для журнала отметка и оценка одного студента за одно
занятие считаются одной ссылкой, включая явно сохранённую пустую оценку.
В истории каждое событие с ID занятия считается отдельной ссылкой.
Счётчики не являются числом уникальных занятий или подтверждением всех событий.
При нечитаемом списке его частичные ссылки не учитываются как проверенные.

Замечание журнала содержит составной технический ID [студент, занятие],
замечание истории — ID события; оба указывают исходный ключ списка.
Они включаются в существующие пагинацию и полный JSON-отчёт.
ФИО, имена преподавателей, аудитории и значения ячеек не раскрываются.
Подписи уточнены: подтверждение конкретной ссылки отделено от всё ещё
непроверенных исторического состава группы и прав автора.

4. АРХИТЕКТУРА И СОХРАННОСТЬ
Чистый индекс строится один раз по истории управляемого расписания и ID
черновиков. Для каждого ID сохраняются отдельные дисциплины и группы,
без склейки составных ID через разделитель и без поиска всего расписания
для каждой ячейки. Ссылки обходятся последовательно с поддержкой отмены.
Отмена внутри индекса или большого списка не возвращает частичный отчёт
и не превращается в сообщение о повреждённой схеме.
Прямой вызов проверки списков без источника занятий явно сообщает,
что ссылки не проверялись. Полная проверка архива передаёт читаемый источник
или его отсутствие; живое расписание при этом не запрашивается.
Записи, миграции, восстановления и изменений рабочей логики журнала нет.
Новые библиотеки не добавлялись.

5. ПРОВЕРКА
Проверен профиль из 495 тестов в 21 файле: проверки архива, ссылки, история,
JSON-отчёт, SSR и существующий journalStore. При общем запуске прошли 494;
единственное оставшееся ожидание старой подписи SSR обновлено отдельно.
После обновления повторно прошли все 21 тест SSR-набора; результаты
повторных запусков не суммируются как уникальные тесты.
Покрыты активная/отменённая/перенесённая пара, прежняя область после переноса,
черновик, отсутствующий ID, чужая область, старые ключи, совпадение даты,
нечитаемое расписание, неизвестная область, пустые оценки, отдельные события,
исключение roster/demo, нечитаемый список, 300 замечаний и отмена.
Общий fixture теперь использует опубликованное занятие со стабильным ID
и соответствующей историей расписания; старые ключи проверяются явно.
TypeScript и общий ESLint прошли. Полный набор портала не запускался.
Production-сборка с базой /BIUniversity/ прошла. check:build подтвердил
97 записей манифеста и 122 файла; browserRuntimeChecked=false.
Проверки diff и планов прошли: 52 архивных хеша, 7 рабочих планов,
72 Markdown-ссылки и 7 кратких пересказов.

6. ЧТО ОСТАЛОСЬ
Определить решения для неподтверждённых ссылок, старых ключей и отсутствующих
источников. Проверить исторических студентов и авторов, доступ и назначения
преподавателей для конкретного занятия, состояния групп и коллизии расписания.
Подтверждённая ссылка не разрешает восстановление и не выбирает значение
из расходящихся журнала и истории.
Ручная приёмка счётчиков, длинных ID, тем, телефона и клавиатуры остаётся
в активном плане G03. Браузер, Computer Use, коммиты и отправка в Git
не выполнялись. Снимок 52 документов от 28 октября не изменён.

КРАТКИЙ ПЕРЕСКАЗ
Архив сверяет стабильные ссылки журнала с историей занятий своей дисциплины
и группы. Черновики, старые ключи, чужие и отсутствующие занятия требуют
проверки; отменённые исторические пары сохраняются без переноса оценок.
