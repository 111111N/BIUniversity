G03: ВЫБРАННЫЕ СПИСКИ, ИСТОРИИ И СТРОКИ ЖУРНАЛОВ
Дата: 23 ноября 2026

Результат
Общая проверка выбранных данных дополнена планировщиками, уведомлениями, историями журналов и снимками журналов. Общий реестр семейств использует существующий механизм соответствия полному сохранённому источнику. Записи только из одного источника сохраняются; смешанный список автоматически не собирается. Ключи сравниваются точно: похожие ID владельцев и учебные области не объединяются. Повреждённый/повторный/неподдерживаемый источник не заменяется другой версией.

Метаданные корня, формат массива/объекта и дополнительные поля защищены от слияния. Формат/служебные поля не выбираются через отдельную строку. Для историй журналов проверяется относительный порядок общих ID: добавление нового события в начало допустимо, перестановка общих событий блокируется. Ранее действующее правило абсолютных позиций остальных базовых историй не менялось. Истории не сортируются и пропущенные события не достраиваются.

Списки проходят существующие инспекторы по выбранным полным учёткам, каталогам и расписанию. Проверяются владельцы планировщиков, получатели уведомлений, учебные области журналов, ID студентов/авторов/занятий, сохранённые утверждения контекста автора, цепочки ячеек и последние применимые события относительно выбранного снимка. Заблокированный снимок остаётся недоступным, а не пустым или заменённым другой версией. Недоступные источники заданий/ответов не подставляются из текущих хранилищ.

Добавлено отдельное сравнение строк журнала по ID студента внутри точного ключа с подтверждённой одинаковой парой ID дисциплины/группы. Для имени, карты посещаемости и карты оценок доступен защищённый просмотр конфликта. Неизвестная/неоднозначная область, непоказанные дополнительные поля и слишком большой полный просмотр не дают выбрать версию. Выбор принимается только после просмотра и повторной проверки файла, доступа, снимка данных и ревизии выбора. Итоговый снимок должен целиком совпасть с одним полным источником; выбор строк не обходит метаданные и не создаёт смешанный журнал.

Техническое сравнение отчёта содержит счётчики, ID, имена изменённых полей и причины несравнимости. Значения ячеек и ФИО в него не включаются. Перед скачиванием проверяется полнота нового сравнения; частичный отчёт не выдаётся за полный. Значения возвращаются только в отдельный авторизованный просмотр.

Время создания задач/уведомлений и сохранения событий журнала проверяется относительно завершения исходного архива или момента общей проверки выбранного набора. Будущая дата начала/окончания задачи или занятия сама по себе допустима. Неизвестная заданная граница времени не заменяется часами устройства. Читаемая ссылка расписания отдельно отмечается как неподтверждённая цель: параметры поиска не задают постоянный ID занятия и не подтверждают исторический доступ.

Сборщик замечаний планировщиков, уведомлений и журналов общий, с дедупликацией и ограничениями числа/текста. Вложенные обходы поддерживают отмену; отмена не превращается в ошибку схемы. Выбор источников ограничен совокупными бюджетами ключей, текста, записей и результата. Превышение и отмена не возвращают частичный успешный итог. UI источников использует общий компонент, поиск, фильтр состояния и страницы по 20. Длинные ключи переносятся в существующей оболочке.
