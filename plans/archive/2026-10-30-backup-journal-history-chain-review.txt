СОСЕДНИЕ ИЗМЕНЕНИЯ ЯЧЕЙКИ В ИСТОРИИ ЖУРНАЛА
Дата: 30 октября 2026
Область: G03 — согласованность сохранившейся последовательности событий.

1. РЕЗУЛЬТАТ
Для читаемой истории сопоставляются соседние сохранённые изменения
одной ячейки: один студент, точный ID занятия и тип attendance/grade.
История сохраняется новыми событиями вперёд; предыдущее значение нового
события сопоставляется с результатом более старого сохранённого изменения.
Дата события не используется для сортировки, ID не переименовываются,
порядок входного массива и значения не меняются.
Расхождение создаёт замечание для проверки с ID более нового события.
Оно не объявляет список нечитаемым и не выбирает значение для восстановления:
причиной могут быть неполные данные или нарушение сохранённого порядка.
После разрыва проверка более старых соседей продолжается независимо.

2. ГРАНИЦЫ И НЕПОЛНАЯ ИСТОРИЯ
Обычный writer сохраняет последние 200 событий. Старейшее сохранённое
предыдущее значение не обязано быть пустой оценкой или unmarked;
начальное состояние и пропущенные события не создаются.
Демонстрационное заполнение может менять несколько ячеек без отдельных
событий: demo разрывает цепочки проверки всего этого списка.
Событие состава разрывает цепочки соответствующего студента. Это намеренно
консервативно и для переименования: возможная история состава не используется
для доказательства непрерывности отметок. Другие студенты сохраняют свои цепочки.
Событие без ID занятия разрывает цепочки данного студента только для своего
типа ячейки. Недопустимое значение с известным занятием разрывает только
эту ячейку; проверка не перепрыгивает через неизвестный переход.
Разные студенты, занятия, поля и отдельные архивные учебные области
не соединяются. Исторические строковые ID с разделителями остаются буквальными.

3. ИНТЕРФЕЙС И СОХРАННОСТЬ
В сводке истории показано число пар соседних изменений из читаемых списков.
Это число сравнений, включая расхождения, а не число событий или подтверждение
полноты истории. При нечитаемых списках общий счётчик событий по-прежнему
не публикуется; известные сравнения явно относятся к читаемым спискам.
Замечания входят в существующие пагинацию и полный JSON-отчёт с ключом
истории и ID события. ФИО, имена авторов и сравниваемые значения не выводятся.
Читаемая схема остаётся отличимой от семантической ошибки значения
и от требующего проверки разрыва последовательности.
Проверка вынесена в чистую функцию с индексами студентов/полей/занятий,
без полного поиска по истории для каждой пары. Отмена поддерживается
внутри большого списка. Живые учётки, расписание и журнал не читаются;
запись, миграция и восстановление не выполняются.

4. ПРОВЕРКА
Основной профиль: 418 тестов в 18 файлах прошли, включая journalHistoryChain,
journalHistoryValues, схемы архива, отчёт, SSR и существующий journalStore.
После уточнения подписи счётчика прошли 67 тестов в трёх затронутых файлах;
наборы не суммируются как уникальные тесты.
Проверены неполное начало, неизменяемый вход, сохранённый порядок при разнице
часов, удаление оценки, чередование полей, разделение студентов/занятий/областей,
границы roster/demo/неизвестного занятия/неверного значения, отсутствие
каскада замечаний, нечитаемый список, 299 разрывов и отмена.
SSR и полный JSON-отчёт подтверждают статус замечания, ID события
и отсутствие исходных значений. Архивные и текущие данные сохраняются.
TypeScript и общий ESLint прошли. Полный набор портала повторно не запускался.
Финальная подпись прошла точечный ESLint. Локальная production-сборка
с базой /BIUniversity/ прошла. check:build подтвердил 97 записей манифеста
и 122 файла; browserRuntimeChecked=false. Проверки diff и планов прошли:
52 архивных хеша, 7 рабочих планов, 69 Markdown-ссылок и 7 кратких пересказов.
Архивный снимок планов не изменён.

5. ЧТО ОСТАЛОСЬ
Принадлежность учебной области, исторические связи с людьми и занятиями,
сопоставление последнего применимого события с сохранённым журналом,
решения для неполных фрагментов и границ истории остаются в плане.
Текущий состав группы, роль автора и текущие значения журнала не подставлялись
вместо исторических данных. Проверка не подтверждает права или возможность импорта.
Реализованная сверка соседних изменений убрана из очереди; визуальная
приёмка счётчика, статусов, длинных ID, тем, телефона и клавиатуры открыта.
Браузер, Computer Use, коммиты и отправка в Git не выполнялись.
Новых библиотек и изменений рабочей логики журнала нет.

КРАТКИЙ ПЕРЕСКАЗ
Архив показывает разрывы между соседними сохранёнными изменениями ячейки,
учитывая неполное начало и границы истории. Значения не восстанавливаются,
персональные данные не раскрываются, журнал и события остаются неизменными.
