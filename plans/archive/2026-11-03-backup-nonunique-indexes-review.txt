СХЕМЫ ДОПОЛНИТЕЛЬНЫХ НЕУНИКАЛЬНЫХ ИНДЕКСОВ
Дата: 3 ноября 2026
Область: G03, совместимость файловых хранилищ архива

ПРОВЕРКА ГЕНЕРАТОРОВ
Три текущих файловых хранилища приложения не используют автоинкремент.
В архивных материалах, учебных файлах и вложениях переписки такая
настройка уже отклоняется как неподдерживаемая схема. Вычисление
следующего ключа и изменение схем не добавлялись.

Для будущего переноса автоинкрементного хранилища недостаточно только
сохранённых записей: удаление записи не уменьшает счётчик генератора.
Текущий формат хранит флаг autoIncrement, но не исходное состояние
генератора. Правила такого переноса остаются открытыми в G03;
максимальный оставшийся ключ не выдаётся за точное состояние счётчика.

НАЙДЕННЫЙ ПРОБЕЛ
Общая проверка дополнительных индексов обходила только уникальные
индексы. Поэтому недопустимое сочетание составного пути и multiEntry
у неуникального индекса оставалось без отдельной ошибки схемы.

ИЗМЕНЕНО
Ограничения составного пути теперь проверяются для всех переданных
дополнительных индексов, даже при отсутствии записей. Пустой составной
путь и составной путь с multiEntry дают invalid-file-index-schema.
Для неуникальных индексов добавлена отдельная сводка ошибок схемы;
счётчики уникальных индексов и коллизий сохраняют прежний смысл.

Повторяющиеся значения поддерживаемого неуникального индекса допустимы.
Его записи не сканируются для поиска коллизий; значения индекса
и содержимое файлов не раскрываются. Проверка остаётся только читающей,
не создаёт индексы и не подтверждает совместимость будущих записей.
Проверка прочих синтаксических ограничений не расширялась этим изменением.

Общий механизм применяется к материалам, учебным файлам и вложениям
переписки. Ошибка проходит через существующие замечания, представление
документов и полный отчёт без нового раздела интерфейса.

ОСНОВАНИЕ
Indexed Database API 3.0, разделы 2.5, 2.11 и алгоритм createIndex:
https://www.w3.org/TR/2026/WD-IndexedDB-3-20261030/#key-path-construct
https://www.w3.org/TR/2026/WD-IndexedDB-3-20261030/#key-generator-construct
https://www.w3.org/TR/2026/WD-IndexedDB-3-20261030/#dom-idbobjectstore-createindex

ПРОВЕРКИ
214 тестов в 5 файлах прошли: файловые индексы, документы архива,
служба проверки, полный отчёт и представление документов.
Новые случаи покрывают ошибочную схему без записей, допустимые повторы,
смешанные индексы, три вида файлов, сохранение всех ошибок после
200-й и отмену. Исходные данные и сведения о содержимом не менялись.

Общий ESLint, TypeScript, production-сборка /BIUniversity/ и check:build
прошли: 100 записей манифеста, 125 ресурсов. Полный набор портала
повторно не запускался. Ручная приёмка остаётся открытой;
browserRuntimeChecked равен false. Computer Use, проверка приложения
в браузере, коммиты, отправка в Git и публикация не выполнялись.

КРАТКИЙ ПЕРЕСКАЗ
Недопустимые составные схемы теперь выявляются и у неуникальных дополнительных индексов; обычные повторы допустимы, а перенос состояния генераторов и будущая совместимость остаются открытыми.
