НЕПРОВЕРЕННЫЕ КЛЮЧИ РЕЗЕРВНОЙ КОПИИ
Дата: 3 ноября 2026
Область: G03, проверка административного архива

НАЙДЕНО И ИЗМЕНЕНО
Неподдерживаемые локальные записи учитывались только числом unchecked.
По результату проверки нельзя было узнать полный перечень ключей,
внутренние схемы которых остались непроверенными.

Инспектор теперь сохраняет uncheckedKeys вместе со счётчиком. Имена
берутся из архива без разбора неизвестных значений и без обращения
к данным браузера. Неподдерживаемые версии известных ключей сохраняют
прежние замечания; новый список не подменяет проверку схем. Между
порциями ключей обрабатывается отмена. Исходный архив не изменяется.

ИНТЕРФЕЙС
Под сводкой размещён свёрнутый список с поиском и страницами по 10 ключей.
Поиск работает по всему перечню, изменение запроса возвращает первую
страницу; общий счётчик не зависит от видимой страницы. Используются
существующие стили, перенос длинных ключей и механизм фокуса пагинации.
Новые цвета, библиотеки и дополнительные разделы настроек не добавлены.
HTML в ключах отображается как текст. Значения записей не показываются.

Если в старом результате осталось только число или часть списка,
интерфейс предлагает повторить проверку вместо ложного пустого списка.
Формат результата допускает отсутствие поля для старых проверок;
это не отменяет проверки полноты при скачивании.

ПОЛНЫЙ ОТЧЁТ
Скачиваемый JSON сохраняет все непроверенные ключи, включая записи
после 200-й. Экспорт отклоняет неполный перечень, повторы и ключи
вне пространства портала. Старый результат без перечня можно скачать
только при нулевом количестве непроверенных ключей. Значения неизвестных
записей в отчёт не копируются. Отчёт не является файлом восстановления.

ПРОВЕРКИ
140 тестов в 7 файлах прошли: документы архива, служба проверки,
полный отчёт, список непроверенных ключей, поиск и пагинация,
представление документов и общий механизм фокуса.

Проверены перечни более 200 ключей, последняя страница, поиск по всему
набору, неверные номера страниц, отсутствие совпадений, HTML в ключе,
неизменность исходных данных и отсутствие содержимого записей в выводе.
Отдельно проверены отмена и отказ скачивания неполного отчёта.

Общий ESLint, TypeScript и production-сборка /BIUniversity/ прошли.
Завершающая проверка артефактов прошла: 100 записей манифеста,
125 ресурсов; browserRuntimeChecked остаётся false. Полный набор
портала повторно не запускался. Состав планов, ссылки, пересказы
и хеши 52 документов неизменяемого снимка проверены отдельно.

Ручная приёмка поиска, раскрытия, клавиатуры, обеих тем и мобильной
компоновки остаётся в G03. Computer Use, браузерная проверка, коммиты,
отправка в Git и публикация не выполнялись. Восстановление данных,
исторические права и схемы неизвестных записей остаются открытыми.

КРАТКИЙ ПЕРЕСКАЗ
Непроверенные ключи доступны в свёрнутом списке с поиском и пагинацией и полностью сохраняются в отчёте; неполный перечень требует повторной проверки без раскрытия содержимого записей.
