ЦЕЛИ УВЕДОМЛЕНИЙ В АРХИВЕ
Дата: 30 октября 2026
Область: G03, ссылки на задания и ответы перед возможным восстановлением

1. ЧТО ИЗМЕНИЛОСЬ
Ссылки уведомлений на конкретное задание и ответ сверяются с читаемыми
списками самого архива. Проверяются точный ID задания, при наличии ID ответа,
принадлежность ответа указанному заданию и совпадение ID дисциплины/группы
в адресе с сохранённой областью задания и архивными каталогами.
Используются только сохранённые определения групп: встроенный baseline
не подтверждает учебную область цели.

Ссылка на другой ID задания у найденного ответа и расхождение области
с найденным заданием отмечаются ошибками. Отсутствующее задание или ответ
требует проверки: уведомление могло остаться после удаления цели.
Другая карточка того же студента, совпадение названия или текста
не используются для подбора замены. Старое задание без ID дисциплины/группы
не получает область по отображаемым названиям.

2. ФОРМАТ ССЫЛКИ И НЕОДНОЗНАЧНОСТЬ
Поддерживается адрес /journal/:subjectId/:groupId с параметром assignment
и необязательным submission. Компоненты декодируются один раз.
Некорректное кодирование, дубли assignment/submission/tab, пустые ID,
ответ без задания, другой маршрут и вкладка, скрывающая задание,
отмечаются как неподтверждённая цель. Значения не нормализуются и не выбираются
по первому параметру. Повторное декодирование ID и выбор группы по умолчанию
не выполняются. Неоднозначные разделители пути не подбираются по каталогу.
Обычные фильтры и фрагмент адреса не становятся частью ID цели.
Небезопасная ссылка уже имеет отдельную ошибку формата и не получает
повторное замечание о цели. Нечитаемый список уведомлений не проверяется
по уцелевшему фрагменту.

3. ГРАНИЦЫ ПРОВЕРКИ
Ссылки на разделы, расписание по дате, профили и другие типы целей
не выдаются за проверенные записи. В сводке они учитываются отдельно
как ссылки вне этой сверки. Права получателя, доступность на историческую дату,
состояние видимости задания и реальная принадлежность не подтверждаются
простым совпадением ID. Текущая роль и назначения не подменяют историю.

Отсутствующий/нечитаемый источник заданий, ответов или каталогов отличается
от читаемого пустого списка. Справочники браузера и встроенные примеры
не подставляются. Старое уведомление без ID сохраняет номер строки
в замечании; постоянный ID и получатель по роли не назначаются.

4. ИНТЕРФЕЙС, ОТЧЁТ И АРХИТЕКТУРА
Сводка уведомлений показывает число целей заданий/ответов, сопоставленных,
неподтверждённых и ссылок вне этой сверки. Семантический конфликт не скрывает
читаемую схему и число уведомлений.
Замечания содержат технический ID уведомления или номер старой строки,
без исходного URL, заголовка, текста уведомления, задания или ответа.
Интерфейс экранирует ID. Полный JSON сохраняет замечания после 200-го.

Индексы заданий и ответов строятся один раз с поддержкой отмены.
Сверка выполняется по уже прочитанным архивным документам;
повторных обращений к хранилищам и поиска по всему списку для каждой ссылки нет.
Адреса не открываются, не переписываются и не передаются в навигацию.
Рабочая генерация уведомлений, маршрутизация и бизнес-логика не менялись.
Новых библиотек, миграций и записи данных нет.

5. ПРОВЕРКА
688 тестов профиля архива в 28 файлах прошли. Полный набор портала
не запускался; результаты повторных узких запусков не суммируются.
Проверены задание и ответ, другая область, ответ от другого задания,
удалённые цели, старые поля, нечитаемые/пустые источники, каталоги без baseline,
Unicode и буквальные символы ID, однократное декодирование, дубли параметров,
неоднозначные маршруты/вкладки, посторонние фильтры и фрагменты адреса.
Проверена отмена построения индекса без частичного результата.
SSR подтверждает счётчики, видимость конфликта и экранирование ID уведомления.
Полный JSON содержит все 205 отсутствующих целей без исходных адресов,
заголовков и текстов; архив и текущие данные не меняются.

TypeScript, общий ESLint, production-сборка с базой /BIUniversity/
и check:build прошли: 97 записей манифеста, 122 файла,
browserRuntimeChecked=false. Проверки diff и планов прошли: 52 архивных
хеша, 7 рабочих планов, 79 Markdown-ссылок и 7 кратких пересказов.

6. ОСТАВШИЕСЯ ЗАДАЧИ
Определить решения конфликтов и сохранения уведомлений об удалённых целях.
Проверить прочие типы целей, реальную доступность и происхождение записей,
исторические права получателя, старых получателей по роли и коллизии
миграции старых уведомлений без постоянного ID.
Ручная приёмка счётчиков, тем, телефона, длинных ID, пагинации и скачивания
отчёта остаётся в G03. Computer Use не использовался.
Коммитов, отправки в Git и публикации нет. Снимок 52 документов
от 28 октября не изменён.

КРАТКИЙ ПЕРЕСКАЗ
Архив сопоставляет цели уведомлений с заданиями, ответами и их учебной областью по точным ID, отличает удалённые и неоднозначные цели от подтверждённых связей и не выдаёт совпадение записи за проверенные права получателя.
