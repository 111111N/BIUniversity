# Копирование расписания — U06

Обновлено 19 ноября 2026 года. В «Действиях недели» можно выбрать исходную группу и сохранённый черновик либо публикацию. Поддержаны разные недели одной группы и одинаковая неделя разных групп; копирование в ту же неделю той же группы запрещено. Архивная группа может быть источником чтения, назначение должно быть действующей группой.

Дни недели и время сохраняются относительно выбранного понедельника. Все занятия получают новые UUID и числовые ID с проверкой уникальности по черновикам, публикациям, журналу и архиву версий. В копии заменяется groupId; снимок старого уточнения преподавателя не выдаётся за назначение новой группы. Исходные занятия и отметки не изменяются, отметки не копируются. ID преподавателей сохраняются как выбранные ссылки, без подбора по ФИО; актуальные имена берутся только для того же ID.

Предпросмотр проверяет дисциплину/группу, типы и периоды назначений, календарь, занятость преподавателей, групп и аудиторий. Для одинаковой недели исходная группа остаётся среди других опубликованных занятий и участвует в проверке пересечений. Старые и новые затрагиваемые даты группы назначения проверяются на закрытие до переноса и повторно перед сохранением. Каникулы и отдельные неучебные даты показываются как замечания перед публикацией; исправимый рабочий список можно перенести для правки.

Применение заменяет только рабочий список, с явным предупреждением о существующих правках. Затем нужны сохранение черновика и отдельная публикация. Перед переносом заново проверяются автор, роли и ревизии всех источников. Изменение расписания, учёток, справочников, календаря или назначений делает прежнюю проверку устаревшей. Повторное нажатие блокируется; поздние ответы скрываются после смены автора или области.

Это расширение прежнего `ScheduleCopyRequest`: sourceGroupId необязателен для совместимости и по умолчанию равен группе назначения. Результат предпросмотра содержит canApply для закрытого периода. Старое внутригрупповое копирование сохраняется. Новая схема хранилища и библиотека не вводились. Серверная транзакция и уникальность между устройствами остаются U08; ручная приёмка — S02.
