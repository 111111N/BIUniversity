# Dropdown

`main` сохраняет форму WeekPicker и рамку 2 px, `compact` — обычный селектор с рамкой 1 px. Поле, меню, ошибки и поиск используют общую палитру. Красная рамка взаимодействия относится к main; у compact рамка нейтральная, кроме ошибки.

Вариант под мышью или клавиатурным фокусом получает насыщенную красную заливку и контрастный светлый текст, включая уже выбранный вариант. Выбранный вариант без наведения сохраняет прежнее оформление; бордовый градиент не подменяет hover.

У compact фон поля — `--ui-dark-primary`, как у общего input и DateTimePicker, в том числе в панели настройщика. У main фон поля совпадает с Card (`--ui-panel`) во всех состояниях. Цвет скрываемой границы стыка берётся из фактического фона поля; фон выпавшего меню остаётся отдельной непрозрачной поверхностью `--ui-field`.

`DropdownSelect` — общая оболочка react-select для Dropdown и SearchMultiSelect. Компонент Menu передаёт фактический placement через React context; это учитывает автоматический перенос меню вверх и сохраняет связь при портале в body. Стили скрывают только примыкающую к меню границу поля и зеркально меняют скругления. Противоположная граница поля и внешние границы меню остаются видимыми. Не определяйте направление по запрошенному menuPlacement=auto или внутренним CSS-классам библиотеки.
