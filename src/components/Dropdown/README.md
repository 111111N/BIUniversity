# Dropdown

Два вида пикеров:

| Название | Вариант | Назначение и оформление |
| --- | --- | --- |
| Навигационный пикер | `navigation` | Самостоятельный элемент главного интерфейса: полукруглая форма WeekPicker, рамка 2 px и фон блока `--ui-panel`. |
| Пикер поля | `field` | Поле внутри интерфейса или формы: скругления 8 px, рамка 1 px и фон общих текстовых инпутов `--ui-dark-primary`. Используется по умолчанию. |

`main` остаётся совместимым именем для `navigation`, `compact` — для `field`. В новых вызовах используйте названия по назначению. Красная рамка взаимодействия относится к навигационному пикеру; у пикера поля рамка нейтральная, кроме ошибки.

Выбранный вариант получает сплошную красную заливку и контрастный светлый текст. Наведение и клавиатурный фокус у остальных вариантов используют прозрачную красную заливку, красную обводку и мягкое внутреннее свечение. Цвет текста остаётся читаемым в обеих темах.

У каждого вида фон самого поля и выпадающего списка одинаковый. Навигационный пикер использует поверхность блока, пикер поля — поверхность инпута через `--dropdown-control`. Это распространяется на выбор демонстрационной учётной записи и множественный выбор групп. Цвет скрываемой границы стыка и фон полосы прокрутки берутся из той же поверхности.

`DropdownSelect` — общая оболочка react-select для Dropdown и SearchMultiSelect. Компонент Menu передаёт фактический placement через React context; это учитывает автоматический перенос меню вверх и сохраняет связь при портале в body. Стили скрывают только примыкающую к меню границу поля и зеркально меняют скругления. Противоположная граница поля и внешние границы меню остаются видимыми. Не определяйте направление по запрошенному menuPlacement=auto или внутренним CSS-классам библиотеки.
