# CancelButton

Общая текстовая кнопка отмены: нейтральный текст без видимой рамки и заливки, при наведении текст красный. Клавиатурный фокус виден; disabled не реагирует на наведение. По умолчанию `type="button"` и подпись «Отмена», `children` позволяет задать «Не сохранять» или другое действие возврата.

Передавайте обычные атрибуты кнопки, обработчик и ref. `size="compact"` используется в нижней строке календаря (40 px вместо обычных 44 px). `className` предназначен для расположения, оформление кнопки остаётся общим. Компонент не закрывает окна и не сбрасывает значения сам — это делает переданный обработчик.
