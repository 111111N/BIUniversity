# Card

Общая оболочка блоков портала по образцу главной: непрозрачная поверхность темы, рамка 2 px, скругление 14 px, отступ 20 px (14 px при ширине до 620 px). Толщина `--ui-frame-border-width` и цвет `--ui-frame-border-color` общие с WeekPicker и кнопками переключения.

```tsx
<Card as="section" aria-labelledby="materials-title" className={styles.materials}>
  <header className={styles.header}>
    <h2 id="materials-title">Материалы</h2>
    <button type="button" onClick={openUpload}>Загрузить</button>
  </header>
  <MaterialList files={files} />
</Card>
```

`as` поддерживает `div` (по умолчанию), `section` и `article`. Обычные HTML-атрибуты, ARIA-атрибуты, обработчики и `children` передаются выбранному элементу; дополнительная обёртка не создаётся. Для `section` задавайте доступное название через заголовок и `aria-labelledby` либо `aria-label`.

Card отвечает за поверхность и внешние отступы. Сетка страницы, заголовки, таблицы, состояния загрузки и кнопки принадлежат содержимому. Локальный `className` используется для компоновки, без повторного определения фона, рамки и скругления. Разреженные и плотные данные не требуют разных компонентов оболочки.

Для вложенных строк, ячеек и небольших областей используйте спокойные разделители или `--ui-panel-muted`, без наращивания крупных карточек. Модальные окна и кликабельные карточки со ссылкой остаются отдельными компонентами со своим поведением; Card не делает блок интерактивным.

Поверхность реализована общим Sass-mixin `card-surface` из `styles/_mixins.scss`. Окна задачи и подтверждения используют его напрямую на существующем диалоге: такой же фон, рамка и скругление, без дополнительной вложенной Card. Отступ окна можно задать параметром mixin; фокус, Escape и прокрутку по-прежнему обеспечивает Modal.
