# EdgeScrollControls

Общие стрелки горизонтальной прокрутки для доски планировщика и сетки расписания. `frameRef` указывает на внешний контейнер с position: relative, `boardRef` — на прокручиваемый элемент; стрелки находятся рядом с ним, вне области перетаскивания.

Доступная стрелка появляется у наведённого края и при клавиатурном фокусе. На сенсорном устройстве доступные стрелки видны постоянно. Недоступные направления скрыты и исключены из Tab. Прозрачная область управления не перехватывает события задач и пар. Соблюдается prefers-reduced-motion.

`boardId` связывает кнопки с областью через aria-controls, `scopeKey` обновляет измерения после смены недели/контекста, `enabled` отключает управление скрытым видом. `step` задаёт шаг в пикселях. Без него шаг равен расстоянию между соседними колонками data-date, включая зазор; одна стрелка листает один день. При отсутствии колонок используется видимая ширина.
