# ArrowButton

Кнопка переключения периода или прокрутки: скруглённый квадрат 44 × 44 px со скруглением 8 px. При наведении фон становится красным, стрелка — белой в обеих темах. Цвета берутся из общих токенов действия. Фокус клавиатуры и disabled поддерживаются обычной кнопкой.

В обычном состоянии используется фон карточки `--ui-panel`, основной цвет текста и рамка 2 px, общая с Card и основным пикером: `--ui-frame-border-width` и `--ui-frame-border-color`. Не подменять её яркой серой рамкой `--ui-control-border` и не приглушать цвет доступной стрелки до состояния disabled. Цвет заливки при наведении `--ui-button-accent-hover` общий с поиском на главной, в тёмной теме — #f54c4c.

```tsx
<ArrowButton label="Предыдущая неделя" direction="left" onClick={showPreviousWeek} />
```

Обязательный `label` задаёт доступное имя, SVG скрыт от экранного диктора. Остальные стандартные атрибуты кнопки и обработчики передаются без изменения. Для оформления соседней текстовой кнопки «Текущая неделя» используется тот же Sass-mixin `navigationControls.button`.

Рисунок берётся из общего ArrowIcon. Для перехода по ссылке применяется ArrowCircle внутри ссылки; он не используется как оболочка переключения недель и месяцев. Не вкладывайте ArrowButton в другую кнопку или ссылку.
