# PickerButton

Обычная кнопка с оформлением главного элемента WeekPicker: скруглённый верх, без верхней границы, общая рамка 2 px и фон карточки. Радиус `--ui-picker-main-radius` общий с основным Dropdown. Красный акцент используется у рамки при наведении, фокусе и выбранном состоянии; сплошной красной заливки нет.

```tsx
<PickerButton aria-pressed={mode === "group"} onClick={() => setMode("group")}>
  Поиск по группе
</PickerButton>
```

Поддерживает обычные атрибуты и события button, включая disabled, className и children; type по умолчанию — button. Для переключателя передавайте aria-pressed. Компонент не добавляет роли списка выбора, стрелку раскрытия и обработку меню.

Для квадратных стрелок переключения периода используйте ArrowButton. Для настоящего выпадающего списка — Dropdown.
