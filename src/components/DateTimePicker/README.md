# DateTimePicker

Общий календарь с необязательным выбором времени. Внизу слева — ввод даты `дд.мм.гггг`, рядом — `чч:мм` при showTime. Поддерживается ввод восьми цифр даты и четырёх цифр времени с цифровой клавиатуры; полное значение форматируется автоматически.

Корректный ввод обновляет внутренний черновик: календарь открывает нужный месяц и выделяет день, колёсики показывают введённое время. Выбор мышью обновляет оба поля. Неполный/ошибочный ввод не заменяет выбранное значение; «Готово» проверяет поля и передаёт результат через onChange. Enter в дате переводит к времени, в режиме без времени применяет выбор; Enter во времени также применяет его. В режиме без времени клик по календарному дню сохраняет быстрый выбор с закрытием. Tab учитывает оба поля.

Без выбранной даты ввод времени подготавливает его для следующего выбора дня. Очистка и запрет очистки, disabled и внешний контролируемый value сохраняются. Blur не применяет черновик к родительской форме; подтверждение неизменённого значения не вызывает повторный onChange. Шаг колеса часов/минут — одно значение; горизонтальные жесты, масштабирование браузера и сенсорная прокрутка сохраняют своё назначение.

Фон поля совпадает с общим input, фон поповера — с поверхностью карточки. Нижние поля имеют компактные календарную/часовую SVG-иконки, табличные цифры и одну рамку; подписи доступны скринридеру без видимого дублирования. Месяц и год в шапке — 15 px, при наведении текст красный; выбранные календарные значения сохраняют заливку.

В нижней строке — общий `CancelButton` и «Готово». «Отмена», Escape, повторное нажатие на поле и закрытие снаружи отменяют внутренний черновик без вызова onChange. Родительская форма не получает промежуточных изменений дня и времени, поэтому не требуется обратный сдвиг зависимых полей задачи. Подготовленное время без выбранной даты также возвращается к исходному. Внешний контролируемый value при обновлении синхронизирует черновик; отмена не перезаписывает независимое внешнее изменение.

Очистка необязательного значения находится в самом поле: отдельная кнопка × рядом с иконкой календаря, с доступным названием. При allowClear=false кнопки нет; disabled блокирует её вместе с календарём. Кнопка не вложена в кнопку открытия. Нижние поля имеют высоту 40 px и flex-обёртку без зазора текстовой базовой линии; иконки центрируются по этой же высоте.
