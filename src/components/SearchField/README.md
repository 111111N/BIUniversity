# SearchField

Общее поле поиска портала, включая главную. Оформление поля задаёт общий mixin `input`, кнопки действия — `navigationControls.button`. Обычный фон поля совпадает с фоном страницы в обеих темах. Локальные копии инпута и его палитры не нужны.

Рамка поля одна во всех состояниях. Фокус выделяет её цветом; не добавляйте полю внешний outline или box-shadow из контейнера страницы.

`label`, `value`, `onChange` обязательны. `withIcon` добавляет декоративную лупу, `error` связывает сообщение с полем. По умолчанию Enter остаётся доступен форме, в которой находится поле.

Для отдельного поиска передайте `onSearch`: появится кнопка с SVG и включится обработка Enter с защитой от запуска во время IME-ввода. `searchButtonLabel` задаёт её доступное название. Кнопка очистки меняет значение и возвращает фокус полю.

`hideLabel` визуально скрывает подпись, сохраняя связь label/input. На главной режим уже указан переключателем, поэтому подпись скрыта, placeholder пустой. Компонент не создаёт form и может использоваться внутри существующих форм.
